Interactive course shell

Setup guide

Seven steps, about forty minutes, no programming. You need a Google account (for Firebase, the free database) and a GitHub account (the free hosting of the site). Everything is done in the browser.

When all steps are green, open Teacher's Edition. Come back to this page at any time: it changes nothing by itself.
